## 🚀 Projetos em destaque

### [RoutineOS](https://github.com/Guilhermee10/routineos)
Plataforma de organização e otimização de rotina pessoal (trabalho, estudos, treino, sono, metas). Tem motor de otimização que encaixa metas flexíveis nos horários livres, calendário semanal, grade de hábitos, streaks, notificações e resumo semanal com IA.
Está **em produção na AWS**.

`Node.js` `Express` `PostgreSQL` `Prisma` `JWT` `React` `Vite` `Jest` `Cypress` `Docker` `GitHub Actions` `AWS`

### [Coxinha Bot](https://github.com/Guilhermee10/coxinha-bot)
Atendente de WhatsApp para uma lanchonete, sendo evoluído para um atendente com IA.

`Python` `Django` `Evolution API` `Gemini API`

### [Cantinho do Yakisoba](https://github.com/Guilhermee10/cantinho-do-yakisoba)
Cardápio digital feito como freelance para um cliente real. Os clientes usam todos os dias, e as vendas pelo Instagram **cresceram 60%**.

`JavaScript` `React`
